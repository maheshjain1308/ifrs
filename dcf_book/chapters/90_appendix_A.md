# Appendix A — Formula Sheet {.unnumbered}

## A.1 Time value of money

| Item | Formula |
|------|---------|
| Future value | FV = PV × (1 + r)ⁿ |
| Present value | PV = FV ÷ (1 + r)ⁿ |
| Effective annual rate | (1 + r/m)ᵐ − 1 |
| NPV | Σ CFₜ ÷ (1 + r)ᵗ |
| Perpetuity | PV = C ÷ r |
| Growing perpetuity | PV = C₁ ÷ (r − g) |
| Annuity | PV = C × [1 − (1 + r)⁻ⁿ] ÷ r |
| Growing annuity | PV = C₁ × [1 − ((1 + g)/(1 + r))ⁿ] ÷ (r − g) |
| Fisher | (1 + nominal) = (1 + real)(1 + inflation) |
| Mid-year factor | 1 ÷ (1 + r)^(t − 0.5) |

## A.2 Operating performance

| Item | Formula |
|------|---------|
| NOPAT | EBIT × (1 − t) |
| Invested capital (operating) | Net fixed assets + operating NWC + intangibles + other operating assets − other operating liabilities |
| Invested capital (financing) | Equity + debt + preference + minorities − cash − non-operating investments |
| ROIC | NOPAT ÷ Invested capital (opening or average) |
| ROIC decomposition | (NOPAT ÷ Revenue) × (Revenue ÷ Invested capital) |
| Reinvestment rate | Net investment ÷ NOPAT |
| Growth identity | g = Reinvestment rate × ROIC |
| Net investment | Capex − D&A + ΔNWC (+ other operating assets) |
| Reinvestment (sales-to-capital) | ΔRevenue ÷ (Sales-to-capital) |
| EVA | NOPAT − WACC × Invested capital |
| MVA | Market value of firm − Invested capital |

## A.3 Free cash flows

| Item | Formula |
|------|---------|
| FCFF (from EBIT) | EBIT(1 − t) + D&A − Capex − ΔNWC |
| FCFF (from EBITDA) | EBITDA(1 − t) + t × D&A − Capex − ΔNWC |
| FCFF (from net income) | NI + Interest(1 − t) + D&A − Capex − ΔNWC |
| FCFF (from CFO) | CFO + Interest(1 − t) − Capex |
| FCFE | NI + D&A − Capex − ΔNWC + Net borrowing |
| FCFE (from FCFF) | FCFF − Interest(1 − t) + Net borrowing |
| FCFE with constant debt ratio δ | NI − (1 − δ) × Net reinvestment |
| Stable-growth FCFE | NI × (1 − g/ROE) |
| Stable-growth FCFF | NOPAT × (1 − g/ROIC) |

## A.4 Discount rates

| Item | Formula |
|------|---------|
| CAPM | Ke = Rf + β × ERP |
| APT | Ke = Rf + Σ βᵢ λᵢ |
| Blume-adjusted beta | 0.67 × raw β + 0.33 |
| Unlevered beta (Hamada) | βᵤ = βₗ ÷ [1 + (1 − t) D/E] |
| Re-levered beta | βₗ = βᵤ × [1 + (1 − t) D/E] |
| Asset beta with debt beta | βₐ = βₑ × E/[E + D(1 − t)] + β_d × D(1 − t)/[E + D(1 − t)] |
| Cash-adjusted beta | β_operating = β_unlevered ÷ (1 − Cash/Firm value) |
| Cost of debt | Kd = Rf + default spread |
| WACC | E/V × Ke + D/V × Kd(1 − t) |
| Unlevered cost of equity | Ku = Rf + βᵤ × ERP |
| ERP with country risk | ERP(mature) + CRP; CRP = default spread × σ_equity/σ_bond |
| Currency conversion of rates | (1 + rᵢₙᵣ) = (1 + rᵤₛᴅ)(1 + Rfᵢₙᵣ)/(1 + Rfᵤₛᴅ) |

## A.5 Valuation

| Item | Formula |
|------|---------|
| Enterprise value (DCF) | Σ FCFFₜ ÷ (1 + WACC)ᵗ + TVₙ ÷ (1 + WACC)ⁿ |
| Terminal value (Gordon) | FCFFₙ₊₁ ÷ (WACC − g) |
| Terminal value (value driver) | NOPATₙ₊₁ × (1 − g/ROIC) ÷ (WACC − g) |
| TV when ROIC = WACC | NOPATₙ₊₁ ÷ WACC |
| TV (exit multiple) | Multiple × Metricₙ |
| H-model | FCFFₙ [(1 + g_s) + H(g_h − g_s)/2] ÷ (WACC − g_s) |
| Equity bridge | EV − debt − preference − NCI + cash + non-operating assets |
| Value per share | Equity to common ÷ diluted shares |
| DDM (Gordon) | P₀ = D₁ ÷ (Ke − g) |
| Stable P/E | Payout × (1 + g) ÷ (Ke − g) |
| Stable P/B | (ROE − g) ÷ (Ke − g) |
| Stable EV/NOPAT | (1 − g/ROIC) ÷ (WACC − g) |
| Excess-return model | Book equity + PV of (ROE − Ke) × opening book equity |
| APV | Unlevered value + PV(tax shield) − expected distress cost |
| PV tax shield (perpetual debt) | t × D |
| Distressed equity | DCF equity × (1 − P) + Distress equity × P |
| VC post-money | Exit value ÷ (1 + IRR)ⁿ |
| Control premium ↔ DLOC | DLOC = 1 − 1/(1 + CP) |
| Cap-rate value | NOI ÷ Cap rate |
| Black–Scholes call | S·N(d₁) − K·e^(−rT)·N(d₂), d₁ = [ln(S/K) + (r + σ²/2)T] ÷ (σ√T), d₂ = d₁ − σ√T |
