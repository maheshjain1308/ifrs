# Appendix A — Formula Sheet {.unnumbered}

## A.1 Basics

| Item | Formula |
|------|---------|
| Present value | PV = FV ÷ (1 + r)ⁿ |
| NPV | Σ CFₜ ÷ (1 + r)ᵗ − Investment |
| IRR | Rate at which NPV = 0 |
| ROI | Return ÷ Investment (use average investment if capital changes) |
| Perpetuity | C ÷ r |
| Gordon model | P₀ = D₁ ÷ (Ke − g) |
| Terminal value | TVₙ = CFₙ × (1 + g) ÷ (r − g) |

## A.2 Asset-based

| Item | Formula |
|------|---------|
| Net asset value (book) | Fixed assets + Net current assets − Long-term debt |
| Net realisable value | Realisable value of assets − Liquidation expenses − Liabilities |
| Replaceable value | Cost of acquiring equivalent assets − Liabilities |
| Goodwill (super profit) | (Maintainable profit − Normal return on net assets) ÷ Capitalisation rate |

## A.3 Income-based

| Item | Formula |
|------|---------|
| Price per share | EPS × P/E |
| Unlisted: adjusted P/E | Peer P/E × (1 − discount for non-listing) |
| Capitalised value | Maintainable profit ÷ Capitalisation rate |
| Capitalisation rate | EPS ÷ Price = 1 ÷ P/E (or CAPM) |
| Weighted average profit | Σ (profit × weight) ÷ Σ weights |
| Gross-up | PBT = PAT ÷ (1 − t) |

## A.4 Cash flow and cost of capital

| Item | Formula |
|------|---------|
| FCFF | EBIT(1 − t) + Depreciation − Capex − ΔNWC |
| FCFE | Net income + Depreciation − Capex − ΔNWC + Net borrowing |
| DCF enterprise value | Σ FCFFₜ ÷ (1 + WACC)ᵗ + TVₙ ÷ (1 + WACC)ⁿ |
| Equity value | EV − Debt − Preference + Cash/non-operating assets |
| CAPM | R = Rf + β(Rm − Rf) |
| APT | R = Rf + β₁RP₁ + β₂RP₂ + … + βₙRPₙ |
| Asset beta | βₐ = βₑ × E/[E + D(1 − t)] + β_d × D(1 − t)/[E + D(1 − t)] |
| Asset beta (β_d = 0) | βₐ = βₑ × E/[E + D(1 − t)] |
| Re-gearing | βₑ = βₐ × [E + D(1 − t)]/E = βₐ × [1 + (1 − t)D/E] |
| WACC | Ke × E/(D + E) + Kd(1 − t) × D/(D + E) |

## A.5 Relative and other approaches

| Item | Formula |
|------|---------|
| Enterprise value | Market capitalisation + Debt − Cash (+ preference + minorities) |
| PEG | P/E ÷ Growth rate |
| Chop-shop value | Average of segment values from capitalisation/sales, /assets, /operating income |
| NOPAT | EBIT − Tax = EBIT(1 − t) |
| Invested capital | Total assets − Non-interest-bearing current liabilities (≈ Equity + Long-term debt) |
| EVA | NOPAT − (Invested capital × WACC) |
| EVA dividend per share | EVA ÷ Number of shares |
| MVA | Market value of firm − Invested capital |
| Financial leverage | PBIT ÷ PBT |
| SVA equity value | PV of FCFs + PV of TV + Non-core assets − Debt |

## A.6 Distressed, start-ups, ESG

| Item | Formula |
|------|---------|
| Expected cash flow | CF × (1 − Probability of distress) |
| Equity (DCF + distress) | DCF equity × (1 − P) + Distress equity × P |
| APV | Unlevered value + Tax benefits of debt − Expected bankruptcy cost |
| Expected bankruptcy cost | (Unlevered value − Distress sale value) × P |
| VC post-money | Exit value ÷ Required multiple (or ÷ (1 + IRR)ⁿ) |
| VC pre-money | Post-money − Investment |
| Scorecard value | Average pre-money valuation × Σ (weight × comparison %) |
| ESG-adjusted cash flow | FCFF − after-tax ESG cost (carbon, welfare, penalties) |

## A.7 Exchange ratio

**Exchange ratio = Fair value per share of target ÷ Fair value per share of acquirer**, where fair value per share = weighted average of values on different bases (e.g., weights 1 for NAV and 3 for earnings capitalisation).
