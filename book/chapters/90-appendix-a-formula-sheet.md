# Appendix A: Formula Sheet

This appendix collects the main formulas of the book, organised by chapter. Each formula is written in plain Unicode and followed by a one-line definition of its symbols. Use it as a quick reference when working problems, and remember that every formula rests on assumptions described in the relevant chapter. Notation conventions: r is a discount rate or required return per period, t or n a number of periods, CF or C a cash flow, g a growth rate, E[·] an expected value, σ a standard deviation, and ρ a correlation.

## Chapter 1: The Corporation and the Finance Function

```
Shareholder wealth = Σ PV(future free cash flows to the firm's investors)
```
The market value of the firm's claims equals the present value of the cash flows it is expected to generate; value maximisation is the guiding objective.

```
Agency cost = monitoring cost + bonding cost + residual loss
```
The total cost of conflicts between owners and managers: what owners spend to monitor, what managers spend to commit, and the value lost despite both.

```
Economic profit = NOPAT − (WACC × Invested capital)
```
Profit remaining after charging for all capital employed; positive economic profit signals value creation.

## Chapter 2: Financial Statements and Ratios

```
Assets = Liabilities + Shareholders' equity
```
The accounting identity linking what the firm owns to how it is financed.

```
Net working capital = Current assets − Current liabilities
```
Short-term resources less short-term obligations.

```
Free cash flow to the firm (FCFF) = EBIT × (1 − T) + Depreciation − CapEx − ΔNWC
```
Cash generated by operations after taxes and reinvestment, available to all capital providers; T is the tax rate.

```
Current ratio = Current assets / Current liabilities
Quick ratio = (Cash + Marketable securities + Receivables) / Current liabilities
Cash ratio = (Cash + Marketable securities) / Current liabilities
```
Liquidity measures of increasing strictness.

```
Inventory turnover = Cost of goods sold / Average inventory
Receivables turnover = Credit sales / Average receivables
Payables turnover = Cost of goods sold / Average payables
Total asset turnover = Sales / Average total assets
Fixed asset turnover = Sales / Average net fixed assets
```
Efficiency measures showing how many times a balance is "turned over" in a period.

```
Days inventory = 365 / Inventory turnover
Days sales outstanding (DSO) = 365 / Receivables turnover
Days payables outstanding (DPO) = 365 / Payables turnover
Cash conversion cycle = Days inventory + DSO − DPO
```
Time measures; the cash conversion cycle is the days between paying suppliers and collecting from customers.

```
Gross margin = (Sales − COGS) / Sales
Operating margin = EBIT / Sales
Net profit margin = Net income / Sales
EBITDA margin = EBITDA / Sales
```
Profitability measures as a share of sales.

```
ROA = Net income / Average total assets
ROE = Net income / Average shareholders' equity
ROIC = NOPAT / (Debt + Equity − Excess cash)
```
Returns on assets, equity and invested capital; NOPAT is net operating profit after tax.

```
DuPont: ROE = (Net income / Sales) × (Sales / Assets) × (Assets / Equity)
```
Decomposes ROE into profit margin, asset turnover and the equity multiplier (financial leverage).

```
Extended DuPont: ROE = (NI/EBT) × (EBT/EBIT) × (EBIT/Sales) × (Sales/Assets) × (Assets/Equity)
```
Five-factor version separating the tax burden, interest burden, operating margin, turnover and leverage.

```
Debt-to-equity = Total debt / Total equity
Debt ratio = Total debt / Total assets
Equity multiplier = Total assets / Total equity
Interest coverage = EBIT / Interest expense
Fixed-charge coverage = (EBIT + Lease payments) / (Interest + Lease payments)
Net debt / EBITDA = (Debt − Cash) / EBITDA
```
Leverage and solvency measures.

```
EPS = (Net income − Preferred dividends) / Weighted average shares
P/E = Price per share / EPS
Market-to-book = Market value of equity / Book value of equity
Dividend yield = Dividend per share / Price per share
Payout ratio = Dividends / Net income
Retention ratio (b) = 1 − Payout ratio
```
Per-share and market-based measures.

```
Sustainable growth rate = ROE × b / (1 − ROE × b)
Internal growth rate = ROA × b / (1 − ROA × b)
```
Growth achievable without new external equity (sustainable) or without any external financing (internal).

```
Enterprise value = Market capitalisation + Debt + Preferred + Minority interest − Cash
EV/EBITDA = Enterprise value / EBITDA
```
Value of the operating business to all capital providers, and a common multiple.

## Chapter 3: Time Value of Money

```
FV = PV × (1 + r)^n
PV = FV / (1 + r)^n
```
Future value and present value of a single sum compounded over n periods at rate r.

```
FV = PV × (1 + r/m)^(m×n)
EAR = (1 + APR/m)^m − 1
FV (continuous) = PV × e^(r×n)
EAR (continuous) = e^r − 1
```
Compounding m times per year; EAR is the effective annual rate and APR the quoted nominal rate.

```
PV of ordinary annuity = C × [1 − (1 + r)^−n] / r
FV of ordinary annuity = C × [(1 + r)^n − 1] / r
PV of annuity due = PV of ordinary annuity × (1 + r)
```
Level payments C at the end (or, for annuity due, the start) of each of n periods.

```
PV of perpetuity = C / r
PV of growing perpetuity = C₁ / (r − g)    (r > g)
PV of growing annuity = C₁ / (r − g) × [1 − ((1 + g)/(1 + r))^n]
```
Payments forever, or growing at g, where C₁ is the first payment.

```
Loan payment = P × r / [1 − (1 + r)^−n]
Interest in period k = r × Balance at start of period k
Principal repaid in period k = Payment − Interest in period k
```
Level-payment amortising loan on principal P.

```
Real rate: (1 + r_real) = (1 + r_nominal) / (1 + π)
Approximate (Fisher): r_nominal ≈ r_real + π
```
Converts between nominal and inflation-adjusted rates; π is inflation.

```
Rule of 72: years to double ≈ 72 / (rate in %)
Exact: n = ln(2) / ln(1 + r)
```
Approximate and exact doubling time.

```
NPV = Σ CF_t / (1 + r)^t, t = 0 … n
IRR: the r satisfying Σ CF_t / (1 + r)^t = 0
```
Net present value and internal rate of return of a cash flow series.

## Chapter 4: Bonds

```
Bond price = Σ C / (1 + y)^t + F / (1 + y)^n
           = C × [1 − (1 + y)^−n] / y + F / (1 + y)^n
```
Price equals the PV of coupons C and face value F discounted at the yield y per period.

```
Current yield = Annual coupon / Price
Yield to call: solve Price = Σ C/(1+y)^t + Call price/(1+y)^T for y
```
Simple income measure and the yield assuming the bond is called at time T.

```
Zero-coupon price = F / (1 + y)^n
Spot rate: (1 + s_n)^n = F / P
Forward rate: (1 + s_n)^n = (1 + s_(n−1))^(n−1) × (1 + f_n)
```
Pure discount bond pricing and the relationship of spot and one-period forward rates.

```
Macaulay duration D = Σ [t × PV(CF_t)] / Price
Modified duration D* = D / (1 + y)
ΔP/P ≈ −D* × Δy + ½ × Convexity × (Δy)²
Convexity = [1 / (P × (1 + y)²)] × Σ [CF_t × t × (t + 1) / (1 + y)^t]
```
Duration is the PV-weighted average time to cash flows; modified duration measures price sensitivity to yield; convexity refines the approximation.

```
DV01 ≈ D* × Price × 0.0001
```
Dollar change in price for a one-basis-point change in yield.

```
Yield = Risk-free rate + Default premium + Liquidity premium + Maturity premium
Expected loss = Probability of default × Loss given default × Exposure
Credit spread ≈ Probability of default × Loss given default (annual)
```
Components of bond yield and a simple decomposition of credit risk.

```
Floating-rate note price at a reset date ≈ Par
Duration of a portfolio = Σ w_i × D_i
```
A floating-rate note reprices to par at resets; portfolio duration is the value-weighted average.

## Chapter 5: Equity Valuation

```
P₀ = Σ D_t / (1 + r_e)^t + P_n / (1 + r_e)^n
```
Share price equals the PV of dividends and the terminal price.

```
Gordon growth: P₀ = D₁ / (r_e − g) = D₀ × (1 + g) / (r_e − g)
r_e = D₁ / P₀ + g
```
Constant-growth dividend model and the implied cost of equity.

```
Two-stage: P₀ = Σ[t=1..N] D₀(1+g₁)^t/(1+r)^t + [D_(N+1)/(r − g₂)] / (1+r)^N
```
High growth g₁ for N years followed by stable growth g₂.

```
g = b × ROE
P₀ = EPS₁ × (1 − b) / (r − g)
PVGO = P₀ − EPS₁ / r
```
Growth from retained earnings, price from earnings, and the present value of growth opportunities.

```
Justified P/E = (1 − b) / (r − g)
Justified P/B = (ROE − g) / (r − g)
PEG = (P/E) / (growth rate in %)
```
Fundamental multiples linked to payout, growth, and return on equity.

```
Residual income model: V₀ = B₀ + Σ [(ROE_t − r_e) × B_(t−1)] / (1 + r_e)^t
```
Value equals book equity plus the PV of earnings above the required return on book equity.

```
Preferred stock value = Dividend / r_p
```
Perpetuity valuation of non-growing preferred dividends.

## Chapter 6: Net Present Value and Investment Criteria

```
NPV = −I₀ + Σ CF_t / (1 + r)^t
Profitability index (PI) = PV of future cash flows / Initial investment = 1 + NPV / I₀
Payback period = Years before recovery + Unrecovered cost / Cash flow in recovery year
Discounted payback: payback on discounted cash flows
```
Core capital-budgeting criteria; accept when NPV > 0, PI > 1, IRR > r.

```
Average accounting return (AAR) = Average net income / Average book value
```
An accounting-based criterion that ignores timing and is not recommended as a primary rule.

```
MIRR = (FV of positive flows at r_reinvest / PV of negative flows at r_finance)^(1/n) − 1
```
Modified IRR assuming explicit reinvestment and financing rates.

```
Crossover rate: r at which NPV_A(r) = NPV_B(r), i.e. IRR of (CF_A − CF_B)
Equivalent annual annuity (EAA) = NPV × r / [1 − (1 + r)^−n]
```
Tools for ranking mutually exclusive projects with conflicting NPV and IRR, or with unequal lives.

```
Capital rationing: choose the set of projects maximising ΣNPV subject to ΣI ≤ Budget
```
When funds are limited, rank by PI where projects are divisible.

## Chapter 7: Capital Budgeting

```
Operating cash flow (OCF) = EBIT × (1 − T) + Depreciation
                          = (Sales − Costs) × (1 − T) + Depreciation × T
FCF = OCF − CapEx − ΔNWC
```
Project cash flow under the bottom-up and tax-shield approaches; T is the tax rate.

```
Straight-line depreciation = (Cost − Salvage) / Life
Depreciation tax shield = Depreciation × T
After-tax salvage = Salvage − T × (Salvage − Book value)
```
Depreciation and its tax effect, and the after-tax proceeds from asset sale.

```
Terminal value (growing) = FCF_(n+1) / (r − g)
ΔNWC_t = NWC_t − NWC_(t−1)
```
Value beyond the forecast horizon, and the investment in working capital.

```
Break-even (accounting): Q = (Fixed costs + Depreciation) / (Price − Variable cost)
Break-even (financial): Q = (Fixed costs + EAC − Depreciation × T) / [(Price − Variable cost) × (1 − T)]
Degree of operating leverage (DOL) = 1 + Fixed costs / OCF = %ΔEBIT / %ΔSales
EAC = PV of costs / Annuity factor
```
Break-even analysis, operating leverage, and equivalent annual cost for cost-minimising decisions.

```
Replacement chain: compare EAC (or EAA) across lives, or repeat each project to a common horizon
Lease-versus-buy: NAL = Cost of asset − PV of after-tax lease payments + PV of lost tax shields
```
Approaches to unequal lives and the net advantage to leasing, discounted at the after-tax cost of debt.

## Chapter 8: Uncertainty and Real Options

```
Expected NPV = Σ p_i × NPV_i
Standard deviation of NPV = √[Σ p_i × (NPV_i − E[NPV])²]
```
Scenario analysis summarising outcomes by probability.

```
Sensitivity = ΔNPV / ΔInput
Expected value of perfect information (EVPI) = E[value with information] − E[value without]
```
How much NPV changes per unit change in an input, and the value of resolving uncertainty.

```
Value of project with option = Static NPV + Option value
Expansion option value ≈ max(0, PV of expansion cash flows − Cost of expansion), probability-weighted
Abandonment value = max(Continuing value, Salvage value)
```
Real-option logic: flexibility has value beyond static NPV.

```
Binomial: u = e^(σ√Δt), d = 1/u, q = (e^(rΔt) − d) / (u − d)
Option value = e^(−rΔt) × [q × V_up + (1 − q) × V_down]
```
Risk-neutral valuation on a binomial tree; q is the risk-neutral probability.

```
Decision tree: roll back from terminal nodes, taking the expectation at chance nodes and the maximum at decision nodes
```
The procedure for sequential decisions under uncertainty.

## Chapter 9: Risk and Return

```
Holding period return = (P₁ − P₀ + D₁) / P₀
Arithmetic mean = (1/N) Σ R_t
Geometric mean = [Π (1 + R_t)]^(1/N) − 1
```
Single-period return and the two averages; the geometric mean measures compound growth.

```
E[R] = Σ p_i × R_i
σ² = Σ p_i × (R_i − E[R])²
Sample variance = Σ (R_t − R̄)² / (N − 1)
Coefficient of variation = σ / E[R]
```
Expected return and dispersion measures.

```
Cov(A,B) = Σ p_i (R_Ai − E[R_A])(R_Bi − E[R_B])
ρ_AB = Cov(A,B) / (σ_A × σ_B)
```
Covariance and correlation (−1 ≤ ρ ≤ +1).

```
Risk premium = E[R] − R_f
Sharpe ratio = (E[R_p] − R_f) / σ_p
Value at Risk (normal) = −(μ − z × σ) × Portfolio value
```
Reward for bearing risk, reward per unit of total risk, and a parametric loss threshold with z = 1.645 (95%) or 2.326 (99%).

```
Variance of an N-asset equal-weighted portfolio = (1/N) × avg variance + (1 − 1/N) × avg covariance
```
Diversification removes firm-specific risk but not the average-covariance floor.

## Chapter 10: Portfolio Theory and the CAPM

```
E[R_p] = Σ w_i E[R_i]
σ_p² = Σ_i Σ_j w_i w_j σ_i σ_j ρ_ij
Two assets: σ_p² = w_A²σ_A² + w_B²σ_B² + 2 w_A w_B ρ_AB σ_A σ_B
```
Portfolio return is the weighted average; portfolio risk depends on correlations.

```
Minimum-variance weight in A = (σ_B² − ρσ_Aσ_B) / (σ_A² + σ_B² − 2ρσ_Aσ_B)
```
Weight of asset A in the two-asset global minimum-variance portfolio.

```
Capital allocation line: E[R_c] = R_f + w × (E[R_p] − R_f); σ_c = w × σ_p
Tangency portfolio maximises the Sharpe ratio
```
Combining the risk-free asset with a risky portfolio; w is the weight in the risky portfolio.

```
β_i = Cov(R_i, R_m) / σ_m² = ρ_im × σ_i / σ_m
CAPM: E[R_i] = R_f + β_i × (E[R_m] − R_f)
Security market line: E[R] plotted against β
```
Systematic risk and the equilibrium required return.

```
Jensen's alpha: α_i = R̄_i − [R_f + β_i × (R̄_m − R_f)]
Treynor ratio = (R̄_p − R_f) / β_p
Information ratio = α_p / Tracking error
Portfolio beta = Σ w_i β_i
```
Performance measures relative to risk.

```
Total variance = β²σ_m² + σ²(ε)
R² = β²σ_m² / σ_i²
Single-index model: R_i − R_f = α_i + β_i (R_m − R_f) + ε_i
Fama-French: R_i − R_f = α + β_m(R_m − R_f) + s × SMB + h × HML + ε
```
Decomposition into systematic and idiosyncratic components, and a multifactor extension.

```
APT: E[R_i] = R_f + Σ β_ik × λ_k
```
Expected return as exposure to each factor k times that factor's risk premium λ_k.

## Chapter 11: Cost of Capital

```
WACC = (E/V) × r_e + (D/V) × r_d × (1 − T_c) + (P/V) × r_p
```
Weighted average cost of capital with market-value weights; V = D + E + P and T_c is the corporate tax rate.

```
r_e (CAPM) = R_f + β_e × MRP
r_e (dividend growth) = D₁ / P₀ + g
r_e (bond yield plus premium) = r_d + risk premium
```
Three estimation approaches for cost of equity; MRP is the market risk premium.

```
Unlevering (no debt beta, no taxes): β_U = β_E × E / (E + D)
Hamada (with taxes): β_L = β_U × [1 + (1 − T) × D/E]
Debt beta adjustment: β_A = β_D × D/V + β_E × E/V
```
Relationships between equity beta, asset beta and leverage.

```
Pre-tax cost of debt: solve Price = Σ C/(1+y)^t + F/(1+y)^n
After-tax cost of debt = r_d × (1 − T)
Flotation-adjusted cost = Net proceeds method: Price × (1 − f) = Σ CF_t/(1+y)^t
```
Cost of debt estimated from yield to maturity and adjusted for flotation f.

```
Project (divisional) discount rate = R_f + β_project × MRP, using a pure-play unlevered beta re-levered to the target structure
Adjusted present value (APV) = Base-case NPV (all-equity) + PV(financing side effects)
Capital cash flow approach: discount at pre-tax WACC
```
Matching discount rates to risk, and the alternative to WACC.

## Chapter 12: Market Efficiency and Behavioural Finance

```
Abnormal return AR_t = R_t − E[R_t]
CAR = Σ AR_t over the event window
Market model: E[R_t] = α + β × R_m,t
```
Event-study building blocks; the cumulative abnormal return (CAR) measures the information effect.

```
Test statistic t = CAR / (σ_AR × √N_days)
Autocorrelation ρ_k = Cov(R_t, R_(t−k)) / Var(R_t)
Variance ratio VR(q) = Var(q-period return) / (q × Var(1-period return))
```
Tests for event significance and predictability; VR = 1 under a random walk.

```
Prospect-theory value: v(x) = x^a for gains; −λ(−x)^b for losses, λ > 1
Net present value of mispricing = Intrinsic value − Market price
```
Loss aversion makes losses weigh more than equal gains; mispricing is the gap between value and price.

## Chapter 13: Raising Equity

```
Pre-money valuation + New investment = Post-money valuation
Investor ownership = Investment / Post-money valuation
Price per share = Pre-money valuation / Pre-money fully diluted shares
```
Venture financing arithmetic.

```
IPO underpricing = (First-day close − Offer price) / Offer price
Gross spread = Offer price × Shares × Spread %
Net proceeds = Gross proceeds − Underwriting fees − Other expenses
```
Costs of going public.

```
Rights offering: Ex-rights price = (N × P_cum + Subscription price) / (N + 1)
Value of one right = P_cum − Ex-rights price = (P_cum − Subscription price) / (N + 1)
```
N rights are needed to buy one new share at the subscription price.

```
Shares issued = Proceeds required / Issue price
Dilution = New shares / (Old shares + New shares)
EPS accretion/dilution = EPS_after − EPS_before
Value per share after issue = (Old shares × P + New proceeds) / (Old shares + New shares)
```
Mechanics of equity issuance.

```
Dual-class voting control = Votes held / Total votes; Cash-flow rights = Shares held / Total shares
```
Wedge between control and economic ownership.

## Chapter 14: Debt Financing

```
Effective cost of a fee-bearing loan: solve Net proceeds = Σ Payments_t / (1 + y)^t
Yield of a term loan: solve Net proceeds = Σ Payments_t / (1 + y)^t
Commitment fee cost = Fee % × Undrawn amount
```
All-in cost of borrowing.

```
Floating-rate coupon = Reference rate + Margin
Swap fixed rate: Σ [df_t × S] = Σ [df_t × Forward_t]
```
Floating coupons and the par swap rate set so that fixed and floating legs have equal present value, with discount factors df.

```
Debt service coverage ratio (DSCR) = Cash available for debt service / (Interest + Principal)
Loan-to-value = Loan / Asset value
Lease liability = PV of lease payments at the incremental borrowing rate
Convertible: Conversion ratio = Par / Conversion price
Conversion value = Conversion ratio × Share price
Conversion premium = Bond price / Conversion value − 1
Convertible value ≥ max(Straight-bond value, Conversion value)
```
Credit capacity, lease capitalisation and convertible bond relationships.

```
Call-adjusted yield: solve Price = PV(coupons to call date) + PV(Call price)
Refunding NPV = PV(interest savings after tax) − (Call premium + Issue costs) after tax
```
Evaluating whether to refinance outstanding debt; discount savings at the after-tax cost of new debt.

## Chapter 15: Capital Structure

```
MM Proposition I (no taxes): V_L = V_U
MM Proposition II (no taxes): r_e = r_0 + (D/E) × (r_0 − r_d)
```
In perfect markets capital structure does not affect firm value; the cost of equity rises with leverage; r_0 is the unlevered cost of capital.

```
MM with corporate taxes: V_L = V_U + T_c × D
MM Proposition II (taxes): r_e = r_0 + (D/E) × (r_0 − r_d) × (1 − T_c)
```
The interest tax shield adds T_c × D (permanent debt).

```
PV of tax shield (fixed debt, perpetual) = T_c × D
PV of tax shield (debt rebalanced to target ratio) = Σ T_c × r_d × D_t / (1 + r_d)^t, using suitable discount rate
Miller: Gain from leverage = [1 − (1 − T_c)(1 − T_e) / (1 − T_d)] × D
```
Value of tax shield, and Miller's model including personal taxes on equity (T_e) and debt (T_d).

```
V_L = V_U + PV(Tax shield) − PV(Financial distress costs) − PV(Agency costs of debt) + PV(Agency benefits of debt)
```
Trade-off theory of capital structure.

```
Expected distress cost = Probability of distress × Cost of distress
Financial leverage effect on EPS: EPS = (EBIT − Interest)(1 − T) / Shares
Break-even EBIT between plans: (EBIT − I₁)(1 − T)/N₁ = (EBIT − I₂)(1 − T)/N₂
Degree of financial leverage (DFL) = EBIT / (EBIT − Interest)
Degree of total leverage = DOL × DFL
```
Practical leverage analysis.

```
Altman Z (public manufacturing) = 1.2 X₁ + 1.4 X₂ + 3.3 X₃ + 0.6 X₄ + 1.0 X₅
```
A well-known distress score where X₁ is working capital/assets, X₂ retained earnings/assets, X₃ EBIT/assets, X₄ market equity/liabilities, X₅ sales/assets.

## Chapter 16: Payout Policy

```
Ex-dividend price drop ≈ Dividend × (1 − T_d) / (1 − T_g)
Total shareholder yield = (Dividends + Net repurchases) / Market capitalisation
Dividend payout ratio = DPS / EPS
```
Price adjustment on the ex-date and total cash returned to owners.

```
Repurchase: Shares retired = Cash spent / Repurchase price
Post-buyback EPS = Net income / (Shares − Shares retired)
Price after repurchase (perfect markets) = Equity value before − Cash spent, divided by remaining shares
Homemade dividends: sell shares worth (Desired cash − Dividend received)
```
Mechanics showing payout irrelevance in perfect markets (Modigliani-Miller).

```
Residual dividend policy: Dividend = Net income − Equity needed for positive-NPV projects
Equity needed = Target equity ratio × Capital budget
Lintner partial adjustment: ΔDiv_t = a + c × (target payout × EPS_t − Div_(t−1))
Target dividend = Target payout × EPS_t; c is the speed of adjustment
Stock split ratio: New shares = Old shares × Split factor; New price = Old price / Split factor
Stock dividend: New shares = Old shares × (1 + Dividend %)
```
Dividend policy rules and share-count adjustments.

## Chapter 17: Working Capital

```
Operating cycle = Days inventory + DSO
Cash conversion cycle = Operating cycle − DPO
Working capital investment = Daily sales × Cash conversion cycle (approx.)
```
Time and capital tied up in operations.

```
Cost of forgoing a trade discount = [d / (1 − d)] × [365 / (Full period − Discount period)]
EAR of forgoing discount = [1 + d/(1 − d)]^(365/(Full − Disc)) − 1
```
Implied cost of not taking a d% early-payment discount.

```
Baumol EOQ-for-cash: C* = √(2 × F × T / k)
Miller-Orr: Spread = 3 × [(3/4) × F × σ² / k]^(1/3); Upper limit = Lower limit + Spread; Return point = Lower limit + Spread / 3
Economic order quantity: EOQ = √(2 × D × S / H)
```
Optimal cash conversions (F trading cost, T total cash need, k opportunity rate, σ² daily variance), and inventory ordering (D annual demand, S order cost, H holding cost per unit).

```
Credit policy NPV = PV(incremental contribution) − Δ Receivables investment − Δ Bad debts − Δ Collection costs
Expected cash from credit sale = (1 − Default probability) × Price / (1 + r)^t − Cost
Average receivables = Credit sales per day × DSO
Float = Average daily receipts × Days delayed
```
Credit decisions and cash-management benefits.

```
Effective rate on a line of credit = Interest + Fees / (Usable funds), annualised
Effective cost with compensating balance = Rate / (1 − Compensating balance %)
```
Short-term financing costs.

## Chapter 18: Options

```
Call payoff at expiry = max(S_T − K, 0)
Put payoff at expiry = max(K − S_T, 0)
Put-call parity: C + K × e^(−rT) = P + S    (no dividends)
Put-call parity (dividends): C + PV(K) + PV(Dividends) = P + S
```
Payoffs and the no-arbitrage relationship between European calls (C) and puts (P).

```
Intrinsic value (call) = max(S − K, 0); Time value = Option price − Intrinsic value
Bounds: C ≥ max(S − K e^(−rT), 0); P ≥ max(K e^(−rT) − S, 0)
```
Lower bounds on option prices.

```
Binomial (one step): Δ = (C_u − C_d) / (S_u − S_d)
Option value = e^(−rΔt) [q C_u + (1 − q) C_d]
q = (e^(rΔt) − d) / (u − d)
```
Replicating portfolio and risk-neutral pricing, where Δ is the hedge ratio.

```
Black-Scholes call: C = S × N(d₁) − K × e^(−rT) × N(d₂)
Black-Scholes put:  P = K × e^(−rT) × N(−d₂) − S × N(−d₁)
d₁ = [ln(S/K) + (r + σ²/2) × T] / (σ × √T)
d₂ = d₁ − σ × √T
```
The Black-Scholes model for European options on non-dividend-paying stock; N(·) is the standard normal cumulative distribution.

```
With continuous dividend yield q: replace S by S × e^(−qT)
Greeks: Delta = N(d₁) (call), N(d₁) − 1 (put); Gamma = n(d₁) / (S × σ × √T); Vega = S × n(d₁) × √T
Theta = time decay; Rho = K × T × e^(−rT) × N(d₂) (call)
```
Sensitivities of option value to price, delta, volatility, time and rates; n(·) is the standard normal density.

```
Equity as a call on firm assets: E = Call(V, K = Face value of debt, T)
Debt = V − E = Risk-free debt − Put(V, K, T)
Warrant value dilution adjustment: Warrant = [N / (N + M)] × Call
```
Merton's model of corporate securities, and dilution-adjusted warrant value (N shares outstanding, M warrants).

```
Strategy payoffs: Covered call = S_T − max(S_T − K, 0)
Protective put = S_T + max(K − S_T, 0)
Straddle = |S_T − K|; Collar = S_T + Put(K₁) − Call(K₂)
```
Common option combinations at expiry (before premiums).

## Chapter 19: Derivatives and Hedging

```
Forward price (no income): F₀ = S₀ × e^(rT)    or  S₀ × (1 + r)^T
Forward price (income yield q): F₀ = S₀ × e^((r − q)T)
Forward price (storage costs and convenience yield): F₀ = S₀ × e^((r + u − y)T)
```
Cost-of-carry pricing, where u is storage cost rate and y is convenience yield.

```
Value of long forward at time t = S_t − K × e^(−r(T − t))
Futures P&L = (F_t − F_(t−1)) × Contract size per day (marked to market)
Basis = Spot price − Futures price
```
Forward valuation, daily futures settlement and basis.

```
Minimum-variance hedge ratio h* = ρ × σ_S / σ_F
Number of contracts N* = h* × (Position size / Contract size)
Beta hedge: N = (β_target − β_portfolio) × Portfolio value / (Futures price × Multiplier)
Duration hedge: N = (D_target − D_portfolio) × P_portfolio / (DV01 of futures × 10,000 basis)
```
Hedge-ratio formulas: ρ is the correlation of spot and futures changes, σ_S and σ_F their standard deviations.

```
Swap value (fixed receiver) = PV(fixed leg) − PV(floating leg)
Fixed-rate swap payment = Notional × Fixed rate × Day-count fraction
Floating leg value at reset ≈ Notional
Cap payoff per period = Notional × max(Reference − Strike, 0) × τ
Floor payoff per period = Notional × max(Strike − Reference, 0) × τ
Forward rate agreement (FRA) payoff = Notional × (Ref − K) × τ / (1 + Ref × τ)
```
Interest-rate swap, cap, floor and FRA relationships; τ is the accrual fraction.

```
Credit default swap spread ≈ Annual default probability × (1 − Recovery rate)
Option-based hedge cost = Premium × Notional
```
Rough CDS pricing and the upfront cost of options hedges.

## Chapter 20: Risk Management and Foreign Exchange

```
Interest rate parity (covered): F / S = (1 + r_d) / (1 + r_f)
Forward premium/discount ≈ r_d − r_f
```
Forward exchange rate F and spot S, quoted as domestic currency per unit of foreign currency; r_d and r_f are domestic and foreign interest rates.

```
Purchasing power parity (absolute): S = P_d / P_f
Relative PPP: E[S₁]/S₀ = (1 + π_d)/(1 + π_f)
International Fisher: (1 + r_d)/(1 + r_f) = E[S₁]/S₀
```
Parity conditions linking exchange rates, inflation and interest rates.

```
Cross rate: S(A/C) = S(A/B) × S(B/C)
Percentage change in foreign currency = (S₁ − S₀) / S₀
Triangular arbitrage profit = ending amount − starting amount after three conversions
```
Cross rates and arbitrage tests for quote consistency.

```
Transaction exposure = Foreign cash flows × Spot rate sensitivity
Money-market hedge: Borrow PV of foreign payable at foreign rate … convert at spot … invest domestically
Forward hedge cash flow = Foreign amount × Forward rate
```
Hedging a foreign-currency receivable or payable.

```
Foreign project NPV = Σ [E[S_t] × CF_t^foreign] / (1 + r_d)^t − I₀ × S₀
Foreign discount rate: (1 + r_d) = (1 + r_f) × E[S₁]/S₀
Value at Risk (portfolio) = z × σ_p × √(horizon days) × Portfolio value
Expected shortfall = Average loss beyond VaR
```
International capital budgeting (consistent domestic or foreign approach) and tail-risk measures.

## Chapter 21: Enterprise Valuation

```
Enterprise value = Σ FCFF_t / (1 + WACC)^t + TV / (1 + WACC)^n
Equity value = Enterprise value − Net debt − Preferred − Minority interest
Value per share = Equity value / Diluted shares
```
Discounted cash flow valuation of the operating business.

```
Gordon terminal value: TV_n = FCFF_n × (1 + g) / (WACC − g)
Exit-multiple terminal value: TV_n = Multiple × EBITDA_n
Implied multiple = TV_n / EBITDA_n; Implied g = (TV × WACC − FCFF_n) / (TV + FCFF_n)
Value-driver formula: TV = NOPAT_(n+1) × (1 − g/ROIC) / (WACC − g)
```
Terminal value methods and cross-checks; ROIC is the return on new invested capital.

```
FCFE = Net income + Depreciation − CapEx − ΔNWC + Net borrowing
Equity value = Σ FCFE_t / (1 + r_e)^t
Net operating profit after tax (NOPAT) = EBIT × (1 − T)
Invested capital = Operating NWC + Net fixed assets + Other operating assets
```
Equity-based cash flow valuation and operating profit measures.

```
Relative valuation: Implied value = Peer median multiple × Target metric
EV multiples: EV/EBITDA, EV/EBIT, EV/Sales
Equity multiples: P/E, P/B
Multiples for cash flows: EV/FCFF
Mid-year discounting: PV = CF / (1 + WACC)^(t − 0.5)
Sum-of-the-parts = Σ (Segment metric × Segment multiple) − Net debt
Control premium = (Offer price − Unaffected price) / Unaffected price
```
Market-based valuation and adjustments.

## Chapter 22: Mergers and Acquisitions

```
Synergy = V_AB − (V_A + V_B)
NPV to acquirer = (V_B + Synergy) − Price paid = Synergy − Premium
Premium = Price paid − V_B (stand-alone)
NPV to target = Premium
```
Value created by a combination and its split between acquirer and target.

```
Cash offer: Cost = Cash paid − V_B
Stock offer: Ownership of target = Shares issued / (Shares_A + Shares issued)
Exchange ratio = Offer price per target share / Acquirer share price
Cost (stock offer) = α × V_AB − V_B,  where α = target's post-merger ownership share
Shares issued = Exchange ratio × Target shares
```
Comparing payment methods; in a stock deal the target shares in synergy and risk.

```
Pro forma EPS = (Net income_A + Net income_B + After-tax synergies) / (Shares_A + New shares)
Accretion/(dilution) = Pro forma EPS / Acquirer EPS − 1
Break-even synergies: solve Pro forma EPS = Acquirer standalone EPS
Combined P/E (weighted) = Combined market value / Combined earnings
Bootstrap effect: EPS rises when acquirer P/E > target P/E in a stock deal without synergy
```
Earnings effects, which do not by themselves indicate value creation.

```
Merger arbitrage spread = (Offer value − Target price) / Target price
Implied probability of completion = (Price − Downside) / (Offer − Downside)
Maximum acquirer price = V_B + Synergy
Takeover premium paid in synergy share = Premium / Synergy
Contingent value rights, earn-outs: payoff = max(0, performance − threshold) × multiple
```
Deal-risk pricing and structuring tools.

Sources = Uses

The balance of funding in a leveraged buyout.

Exit equity = Exit multiple × EBITDA_exit − Net debt_exit

Liquidation value vs going-concern value: restructure if Going-concern value > Liquidation value
Recovery rate = Recovery / Claim; Absolute priority: senior claims paid in full before junior

```

## Quick Reference: Key Decision Rules

```
Accept project if NPV > 0

Accept project if PI > 1
Price a security as the PV of its expected cash flows at a risk-adjusted rate
Required return for risk: R_f + β × MRP
Optimal capital structure minimises WACC and maximises firm value

## Notes on Use

Three cautions apply to every formula in this appendix. First, check the timing convention: most annuity and bond formulas assume cash flows at the end of the period, and a mismatch between the rate period and the cash-flow period is the most frequent source of error. Second, keep consistency between cash flows and discount rates: nominal cash flows take nominal rates, real cash flows take real rates, after-tax flows use after-tax rates, and flows to equity use the cost of equity. Third, treat formulas as models: each depends on assumptions such as constant growth, perfect markets, normal returns, or no default, and the manager's task is to judge when those assumptions are acceptable and when to adjust.
